# KaamSetu

KaamSetu is a service marketplace platform that connects customers who need work done with workers looking for jobs.

## Tech Stack

### Backend
- Python
- Django
- Django REST Framework
- PostgreSQL
- JWT Authentication

### Frontend
- React
- Vite
- Axios
- React Router

## Core Workflow

Customer:

Register → Post Work → Receive Applications → Select Worker → Track Work → Approve → Review

Worker:

Register → Browse Work → Apply → Get Selected → Start Work → Submit Work
